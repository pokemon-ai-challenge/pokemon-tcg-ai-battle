# alakazam_xerosic — フーディン(超/手札干渉型)テンプレ

上位陣フーディンデッキ(超タイプ / 手札干渉型)の top10 テンプレをカードID化したもの。
**現行 `sample_submission/deck.csv` は変更していない。** これは差し替え候補の実験用デッキ。

狙い: 実 Kaggle 対戦で最大の弱点だった**フーディン・ミラー(alakazam 2-6)**の改善。仮説は
「以前のデッキが**クセロシキのたくらみ(手札干渉)**を積んでいなかったからミラーで不利」。
このデッキで現行デッキと対戦させて検証する。

## 現行 deck.csv からの差分

現行の検証済みIDを流用し、以下だけ変更(合計は60維持):

- **+クセロシキのたくらみ ×3(新規, ID 1197)** ← 手札干渉。ミラー改善の本命。
- スタジアム入替: **バトルコロシアム ×3 → 夜の鉱山 ×2(新規, ID 1266)**
- **ワンダーパッチ ×2 → 抜き**
- テレパス【超】 ×2→4 / 基本【超】 ×4→2(エネ構成の特殊寄せ)
- 改造ハンマー ×3→4 / ヒカリ ×3→4 / 夜のタンカ ×2→1 / ノココッチ ×3→2

## 使い方(現行デッキとの対戦テスト)

```
python league/run_league.py --agent-a ml_policy --agent-b ml_policy \
  --deck-a experimental_decks/alakazam_xerosic/deck.csv \
  --deck-b sample_submission/deck.csv \
  --games 200 --workers 12
```

両者とも現行 production config・現行 Policy 重み(構成C)でパイロットする(模倣学習の再学習は
不要。PolicyModel はデッキ非依存で、渡されたデッキをそのまま操作する)。A(新デッキ)の勝率が
50% を有意に超えれば、ミラー改善の証拠になる。
