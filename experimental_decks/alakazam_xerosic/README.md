# alakazam_xerosic — フーディン(超/手札干渉型)テンプレ

上位陣フーディンデッキ(超タイプ / 手札干渉型)の top10 テンプレをカードID化したもの。
**現行 `sample_submission/deck.csv` は変更していない。** これは差し替え候補の実験用デッキ。

狙い: 実 Kaggle 対戦で最大の弱点だった**フーディン・ミラー(alakazam 2-6)**の改善。仮説は
「以前のデッキが**クセロシキのたくらみ(手札干渉)**を積んでいなかったからミラーで不利」。
このデッキで現行デッキと対戦させて検証する。

## 現行 deck.csv からの差分

現行の検証済みIDを流用し、以下だけ変更(合計は60維持):

- **+クセロシキのたくらみ ×3(新規, ID 1197)** ← 手札干渉。ミラー改善の本命。
- スタジアム入替: **バトルコロシアム ×3 → 夜の鉱山 ×2(新規, ID 1266)**
- **ワンダーパッチ ×2 → 抜き**
- テレパス【超】 ×2→4 / 基本【超】 ×4→2(エネ構成の特殊寄せ)
- 改造ハンマー ×3→4 / ヒカリ ×3→4 / 夜のタンカ ×2→1 / ノココッチ ×3→2

## 使い方(現行デッキとの対戦テスト)

```
python league/run_league.py --agent-a ml_policy --agent-b ml_policy \
  --deck-a experimental_decks/alakazam_xerosic/deck.csv \
  --deck-b sample_submission/deck.csv \
  --games 200 --workers 12
```

両者とも現行 production config・現行 Policy 重み(構成C)でパイロットする(模倣学習の再学習は
不要。PolicyModel はデッキ非依存で、渡されたデッキをそのまま操作する)。A(新デッキ)の勝率が
50% を有意に超えれば、ミラー改善の証拠になる。

## 対戦テスト結果(2026-07-25、デスクトップ 200試合、両者 abl_5_full・同一Policy)

**A=新デッキ vs B=旧デッキ(現行deck.csv): A 142/200 = 0.710 (Wilson95%CI[0.644,0.768])** → 新デッキが有意に強い。
先手0.730/後手0.690、エラー0。クセロシキ(手札干渉)+スタジアム/エネ調整でミラーが大きく改善。

## 対フィールド測定(2026-07-25、デスクトップ 各100試合、config=full固定)

`league/field_gauntlet_deck.py`。契約者=full固定でデッキだけ new/cur を振り、メタ7アーキ相手の
対フィールド期待勝率を比較。**結果: 新デッキはミラー特化で、フィールドでは逆に劣後。**

| 相手 | new | cur | Δ |
|---|---|---|---|
| mega_lucario_ex | 72 | 80 | -8 |
| archaludon_ex | 74 | 84 | -10 |
| crustle | 43 | 36 | +7 |
| dragapult_ex | 89 | 94 | -5 |
| marnie | 58 | 59 | -1 |
| rocket_mewtwo | 36 | 32 | +4 |
| shirona | 75 | 72 | +3 |

**対フィールド期待勝率(メタシェア加重): new 66.7% / cur 70.4%(Δ -3.8pt 劣後)。**
mirror(alakazam)では new が cur に 0.710 で圧勝するが、フィールド2大シェア(mega_lucario/archaludon)で
大きく落ちる。実対戦は非ミラーが多数派(~83%)なので、新デッキは実ラダーでNET劣後の可能性が高い。
=> 「ミラーだけ強い ≠ 総合強い」。full+新デッキ提出(54959380)は旧デッキ(717付近)を下回るリスク。
結果json: results/field_gauntlet_deck/_gauntlet_deck_matrix.json。
