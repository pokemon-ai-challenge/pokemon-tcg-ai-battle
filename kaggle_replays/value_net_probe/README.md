# value_net_probe — 価値関数が「いつ」役に立つかの調査

強化学習の credit assignment に価値関数(critic)を使う前に、**どのターン帯で勝敗を予測できるのか**を測る。
全ターン平均の AUC では終盤に引っ張られて、序盤に情報が無いことが見えない。

## 出発点

チーム既存の `kaggle_replays/value_net/evaluate_results.json`(4,698リプレイ)のターン帯別 AUC:

| ターン帯 | 価値関数 | サイド差 |
|---|---:|---:|
| 1-2 | **0.530** | 0.499 |
| 3-5 | 0.656 | 0.574 |
| 6-10 | 0.778 | 0.735 |
| 11+ | 0.839 | 0.752 |

全体 0.746 という数字は当たって当然の終盤の平均。**序盤はコイン投げ同然。**

## 測定の作法(ここを外すと結果が嘘になる)

- **分割は試合単位。** リプレイ由来のデータは同一 `episode_id` に両プレイヤー視点の行が入り、ラベルが完全に反対。行単位で分割すると漏洩して AUC が不当に上がる。`GroupKFold(groups=episode_id)` を使う
- **信頼区間は試合単位のクラスタブートストラップ。** 局面数を独立標本として扱うと区間が不当に狭くなる。実効サンプルは試合数に近い(300試合 / 45,949行)

## ファイル

| ファイル | 内容 |
|---|---|
| `early_game_signal.py` | 本体。ターン帯別に単一特徴・LR・GBM の out-of-fold AUC を出す |
| `add_matchup_column.py` | npz に `matchup` 列(learner vs opponent)を足す。「盤面を見ずマッチアップだけを見るモデル」のベースライン用 |
| `*_results.json` / `*.md` | 測定結果 |

`early_game_signal.py` は `--npz` / `--group-col` / `--extra-baseline-col` で任意のデータセットに使える。
既定引数では `kaggle_replays/value_net/features.npz` を `episode_id` で分割する。

## 結果の要約

**上位リプレイ300試合(本ブランチのデータ)では決着せず。** 区間が広すぎた。
試合数が300しかなく、166特徴のモデルを当てるには実効サンプルが足りない。
症状として、手で選んだ1特徴 `bench_count_diff`(AUC 0.574)が学習済みモデル全部(0.527〜0.533)を上回った。

**自己対戦4,000試合で決着。** ターン1-2 の AUC は 0.685 [0.667, 0.702] で、序盤は予測可能だった。
ただし**盤面を一切見ずマッチアップだけを見るモデルが 0.652** [0.632, 0.670] で、差はごく僅か。
permutation importance の1位も `opp_active_best_attack_damage`(2位の2.5倍)で、
これは局面の質ではなく**相手がどのデッキかを言い当てる特徴**。

温度1.0(PPO が実際に収集する分布)では 0.634 [0.605, 0.666] 対 0.620 [0.591, 0.651] で、
区間がほぼ完全に重なる。**RL の収集分布では、序盤において盤面はマッチアップ以上の情報をほとんど持たない。**

### これが RL にとって意味すること

マッチアップは1試合の中で変化しない。critic がそれを読んでいるだけなら、序盤の各決定に対する
価値がほぼ一定になり、shaping 項 `γΦ(s') − Φ(s)` がゼロに近づく。**どの手が良かったかを区別できない。**

ただし試合ごとの難易度を捉えるベースラインは advantage から試合間分散を除くので、
分散削減としては機能する。**「ベースラインとしては有用、credit assignment としては無力」**という切り分け。

なお GBM が LR を大きく上回る(0.685 vs 0.621)。関係は強く非線形で、線形 critic では取りこぼす。

### 未測定

critic の予測値が**同一試合の序盤の決定間でどれだけ動くか**(試合内分散 vs 試合間分散)。
試合内分散がほぼ0なら序盤の credit assignment は原理的に不可能で、
序盤は模倣学習・RL はターン6以降、という設計が確定する。
