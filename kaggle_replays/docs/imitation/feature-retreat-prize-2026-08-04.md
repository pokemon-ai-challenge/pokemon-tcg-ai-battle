# にげるコスト・サイド価値の追加は効かなかった（2026-08-04）

> **状態: 有効（結論確定・不採用）** — 実装は revert 済み。同じ案を再度試さないための記録。

## 何を試したか

ポケカの立ち回りから見て、**観測できるのに方策へ渡していない情報**を2つ見つけたので追加した。

| 特徴 | 出所 | なぜ必要と考えたか |
|---|---|---|
| `retreat_cost` | `CardData.retreatCost` | 逃げの判断は「下げたいか」ではなく「何個エネを捨てて下げるか」で決まる。逃げ0で回転できる相手と逃げ3で縛られる相手では打ち手が変わる |
| `prize_value` | `CardData.ex` / `megaEx`（1 / 2 / 3枚） | ポケカの勝敗はサイド6枚の取り合い。盤面の各ポケモンが何枚分の的かが分からないとサイドレースの計算ができない |

`_pokemon_features()` に2次元追加（11→13）。状態側 166→190、選択肢側も
`target_pokemon_*` が同じリストを再利用しているため 65→67 に増えた。

きっかけは誤答の分解（→ [bc-retrain-2026-08-03.md](bc-retrain-2026-08-03.md) と
`diagnose_errors.py`）で、**にげるの一致率が 0.40 と突出して低い**と分かったこと。

## 結果: 効果なし

対照群は `--ablate-features retreat_cost,prize_value` で同じ2特徴を 0 で潰したもの。
**次元・データ・プールはすべて同一で、2特徴の情報の有無だけが違う。** 各3シード。

### オフライン（Top-1 一致率、marnie 85,218決定点）

| | 実験群 | 対照群 | 差 |
|---|---:|---:|---:|
| 全体 | 0.7350 ±0.001 | **0.7381 ±0.002** | −0.3pt |
| にげる | 0.4966 ±0.103 | 0.4827 ±0.098 | +1.4pt |
| 進化 | 0.5234 ±0.020 | **0.5692 ±0.046** | −4.6pt |

### 対戦勝率（凍結プール・各1,200試合・学習なし）

| | 勝率 | n |
|---|---:|---:|
| 実験群（3シード） | 0.5608 | 3,600 |
| 対照群（2シード） | 0.5521 | 2,400 |
| 差 | +0.9pt | p=0.504 |

**オフラインでも勝率でも差が無い。** むしろオフラインは全体でわずかに悪化している
（入力次元が26増えたぶん学習が難しくなり、価値の無い情報にパラメータを割いたと解釈）。
→ **不採用。エンコーダの変更は revert 済み。**

## 途中で2回、誤った結論を出しかけた

記録として残す。**どちらも対照群を用意せず、少ないシードで判断しようとしたことが原因。**

1. **2シードで「retreat +8〜14pt、効果あり」と報告した。** 3シード目で 0.4378 が出て崩れた。
   にげるは n=788 と小さく、run 間で ±10pt 振れる。効果量と同じオーダーだった。
2. **対照群の初回評価で「実験群が +26.8pt で圧勝」と出た。** これは評価側のバグ。
   潰した列の std は 0 ではなく **1e-6 にクリップ**されるため、評価時に実データを入れると
   `(2 - 0) / 1e-6 = 2,000,000` が入り、対照群だけ数値が壊れていた。
   学習ログ（0.7383）と診断結果（0.4675）が食い違ったことで気づいた。

対策として `train.py --seed` と `--ablate-features`、`diagnose_errors.py --ablate-features` を追加した。
**対戦評価に使う場合は、潰した列の std を 0 に書き換える必要がある**（`_forward` の
「std が偽なら 0」経路へ落とすため）。潰したまま学習した重みをそのまま推論に回すと同じ罠を踏む。

## この案から言えること

- **にげるの一致率 0.40 は「情報が足りない」だけでは説明できない。** にげるコストを渡しても改善しない
- 小さな特徴を1〜2個足すやり方では、この規模のモデル・データでは勝率は動かない
- 次に狙うなら、**手札の中身**のように情報量の大きい欠落（現在は
  「ポケモン何枚・トレーナー何枚・エネ何枚」の3つの数しか渡していない）

## 残っている疑問

- 進化の −4.6pt は3シードとも一貫していたが、なぜ悪化したかは説明できていない
- 対戦勝率の対照群は2シードで確定（3本目はキュー待ちのまま打ち切り）。
  差が p=0.50 と大きく離れているため結論は変わらない
