# 最悪マッチアップ（marnie vs crustle）の構造分析（2026-08-06）

> **状態: 有効** — 勝率 0.589 の原因を、カードテキストと敗因内訳の両方から特定した。
> **方策の学習不足ではなく、デッキ相性とプランの問題。**

## 1. 敗因の内訳（n=1,200、marnie bc2）

| 終局理由 | crustle戦 負け | crustle戦 勝ち | alakazam戦 負け |
|---|---:|---:|---:|
| サイドを取り切られた／取り切った | 79.1% | 74.4% | 88.0% |
| **山札切れ** | **17.6%** | 2.0% | **0.5%** |
| ベンチ切れ | 3.2% | 23.6% | 11.5% |

**山札切れ負けが alakazam 戦の 35倍。** しかも山札切れ試合は平均 34.7ターン（通常19.1、alakazam戦13.1）。
**長期戦に引きずり込まれて自滅している。**

## 2. カードテキストが示す構造

```
イワパレス (HP150, 非ex=1枚取り)
  特性 Mysterious Rock Inn : 相手の ex ポケモンの攻撃によるダメージをすべて防ぐ
  ワザ Superb Scissors 120 : このワザのダメージは相手のバトルポケモンへの効果に影響されない

マリィのオーロンゲ ex (HP320)
  Shadow Bullet 180 : 相手のベンチ1体にも30ダメージ
```

marnie 側のアタッカー一覧:

| カード | 枚 | ex | HP | 打点 |
|---|---:|---|---:|---:|
| マリィのオーロンゲ ex | 3 | ex | 320 | 180（+ベンチ30） |
| Munkidori | 4 | − | 110 | 60 |
| マリィのモルペコ系 Morgrem | 3 | − | 100 | 60 |
| Froslass | 2 | − | 90 | 60 |
| Marnie's Impidimp | 4 | − | 70 | 10 |
| Snorunt | 2 | − | 70 | 10 |

### ここから読める3つの事実

**① 主砲が完全に無効化される。** オーロンゲex の 180 打点は 0 になる。

**② ex 以外は殴れるが、1発で落とされる。**

```
イワパレスの打点 120
  Munkidori  HP110 → 1発で落ちる
  Morgrem    HP100 → 1発で落ちる
  Froslass   HP 90 → 1発で落ちる
```

**非exアタッカーは全員がワンパン圏内。** しかも 60 打点なので、HP150 のイワパレスを倒すのに**3回攻撃**が要る。
「3回殴る前に1回で落とされる」ので、**普通に殴り合うと絶対に勝てない。**

**③ サイドレースの算術が成立しない。**

```
イワパレスは非ex = 1枚取り
サイド6枚 = 6体KO = 60打点なら最大18回の攻撃
```

実測の平均19.1ターン、山札切れ34.7ターンはこの算術と一致する。**60枚のデッキが先に尽きる。**

## 3. 唯一成立しうる勝ち筋

**オーロンゲex を壁にして、ベンチを削る。ただし Shaymin がいない間だけ。**

- オーロンゲex は HP320。イワパレスの 120 打点に**3回耐える**（唯一ワンパンされないアタッカー）
- Shadow Bullet の本体 180 は無効化されるが、**ベンチへの30ダメージは別**。
  イワパレスの特性は「このポケモンへのダメージ」を防ぐだけなので、**ベンチの Dwebble(HP70) には通る**
- Dwebble を先に落とせばイワパレスの供給が止まる

実測で**勝ちの23.6%がベンチ切れ**なのは、この筋が偶然成立している証拠。
alakazam 戦（11.5%）の2倍。

### 訂正（2026-08-06）— Shaymin を見落としていた

**crustle デッキには Shaymin(343) が1枚入っている。**

```
Shaymin  Flower Curtain
  相手のポケモンの攻撃による、自分のベンチのルールボックスを持たない
  ポケモンへのダメージをすべて防ぐ
```

crustle 側のルールボックス無しポケモンは **Dwebble(4) / Crustle(4) / Shaymin(1) の全部**。
つまり **Shaymin が場に出ている間、Shadow Bullet のベンチ30は Dwebble に通らない。**

上の「特性はこのポケモンへのダメージを防ぐだけなのでベンチには通る」は、
イワパレスの特性については正しいが、**Shaymin という別の防壁を見ていなかった**。
1枚積みなので常時ではなく、勝ち筋が消えるわけではないが、**条件付きになる**。

なお現行の `damage_prevented()` は Shaymin を認識していないので、
方策・価値関数・葉評価はいずれも「ベンチ30が常に通る」と誤って見ている（→ ロードマップ A8）。

## 4. ユーザー指摘の2点は、どちらも正しい

### 「ex 以外のアタッカーで殴る」

**アタッカーは存在するが、単純な殴り合いでは負ける**（②の通り全員ワンパン圏内）。
正しくは「**ex を壁にして、非exは温存する／ベンチを削る**」。
つまり**アタッカーの選択だけでなく、役割の使い分け**が要る。

### 「山札を掘る速度を落とす」

**これが決定的に重要。** 負けの17.6%が山札切れで、alakazam戦の35倍。
現在の方策は「引けるだけ引く」ので、長期戦になる相手に対して**自滅を加速している**。

状態特徴に `self_deck_count`（山札の残枚数）は入っているが、
**「あと何ターンで尽きるか」という速度の情報がない**。34.7ターンの試合で
モデルが危機を認識できているかは疑わしい。

## 5. これが示す設計上の含意

**この問題は特徴量の追加では直らない。** 必要なのは:

| 必要なもの | 種類 |
|---|---|
| 主砲が無効化されていることの認識 | 打点計算（**2026-08-06 に修正済み**、+15.0 Elo / p=0.079） |
| 倒せないときに壁に回るプラン変更 | **探索 or ルールベース**。1手先の評価では出てこない |
| ベンチを削って供給を止める | 同上。数ターン先の計画 |
| 山札の消費速度を落とす判断 | **リソース管理**。切り順のセオリー（手札を小さく保つ）とは逆方向 |

**いずれも「1手ずつの模倣」の守備範囲外。** BCは「上位プレイヤーがこの局面でどうしたか」を
真似られるが、**教師データにこのマッチアップが十分含まれている必要がある**
（crustle の教師は1,272試合、うち marnie 対面は一部）。

## 6. 測定への示唆

**打点修正の効果は、勝率ではなく「山札切れ負けの割合」で測るほうが鋭い。**
全体の勝率だと 17.6% の部分が薄まって p=0.079 にしかならないが、
山札切れ率を直接見れば、少ない試合数で判定できる。

以後、`eval_diagnostics.py` の敗因内訳を**評価の標準出力**に含める。
