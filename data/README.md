# data/

コンペが提供するカードデータです。デッキ構築・カード調査の際に参照します。

## ファイル一覧

| ファイル | 内容 |
|----------|------|
| `Card_ID List_EN.pdf` | カード一覧 PDF (英語版) |
| `Card_ID List_JP.pdf` | カード一覧 PDF (日本語版) |
| `EN_Card_Data.csv` | カードデータ CSV (英語) |
| `JP_Card_Data.csv` | カードデータ CSV (日本語) |

## 注意

これらのファイルはコンペが提供するものです。直接編集しないでください。

カードの検索・絞り込み・印刷には [`cardlist_referenced/pdf_card_editor`](../cardlist_referenced/README.md) を使用すると効率的です。
