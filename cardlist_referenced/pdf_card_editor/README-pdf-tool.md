# Card PDF Editor

ポケモンカード用 PDF を、`見るための一覧` と `使うためのカード管理` に分けて扱うためのローカルアプリです。  
このツールは、カードを 1 枚ずつ確認しながら `作業リスト` を作り、その結果をあとから保存・再開し、必要に応じて `作業リストだけの PDF` や `印刷用 PDF` を書き出すことを目的にしています。

## このアプリの使用目的

- 大量のカード PDF から、必要なカードだけを整理したい
- 一度選んだカード群をあとで開き直して、追加・削除・ラベル修正を続けたい
- 印刷したいカードだけを実寸でまとめて面付けしたい
- 元 PDF を壊さずに、作業用の状態を別で保存したい

このアプリでは「カードを削除する」というより、`作業リストに入れるカードを選ぶ` 方式で管理します。  
そのため、元 PDF に戻らなくても、保存済みプロジェクトを開いて作業リストを増減しながら再編集できます。

## 現在の仕様

### 1. カード一覧

- 左側に全カードを一覧表示します
- 検索、ラベル絞り込み、並び替え、ラベル順グループ化ができます
- 一覧は `通常カード → 作業リスト中のカード` の順に並びます
- 一覧の上部で `表示中を全部選択` `表示中の選択解除` `作業リストを選択` `印刷キューを選択` ができます
- チェックを入れただけでは確定されず、`選択を反映` を押したときに右側の操作パネルへ反映されます

### 2. 画像プレビュー

- カード名にカーソルを合わせると、重ね表示のプレビューが出ます
- カード名をクリックすると、プレビューを固定表示できます
- 固定表示したプレビューは `×` で閉じられます

### 3. 作業リスト

- `作業リストに追加` で、選択中カードを作業対象として登録します
- `作業リストから外す` で、不要になったカードを作業対象から外せます
- `作業リストを空にする` で、現在の作業対象をすべて外せます
- ページ番号から対応カードを解決し、`ページ番号を作業リストへ反映` することもできます
- 作業リスト内のカードは一覧の下側セクションにまとまって表示されます

### 4. ラベル管理

- 選択中カードに対してラベルを付けられます
- 既存ラベルの選択と、新規ラベル入力の両方に対応しています
- ラベル解除もできます
- ラベルは PDF 本体には書き込まず、状態ファイル側に保存します

### 5. 印刷キュー

- 印刷対象は `作業リストに入っているカードだけ` です
- 作業リストへ入ったカードは、既定で `1 枚ずつ` 印刷キューに入ります
- 印刷キューでは枚数変更、並べ替え、ラベル順並べ替え、クリアができます
- 作業リストから外したカードは、印刷キューからも自動で外れます

### 6. PDF 書き出し

- `作業リストだけでPDFを書き出す`
  - 作業リストに入っているカードだけを残した PDF を新規出力します
  - 元 PDF は変更しません
- `印刷用PDFを書き出す`
  - カード画像を抽出して、A4 上に実寸面付けした PDF を出力します
  - 既定ではカードサイズ `63mm x 88mm`、カード間隔 `2mm`、`auto` で最大枚数配置です

### 7. プロジェクト保存

- `新規作成`
  - 現在の PDF をプロジェクト用フォルダへコピーし、作業状態を保存します
- `上書き保存`
  - 現在の作業リスト、ラベル、印刷キュー状態を保存します
- `開く`
  - 保存済みプロジェクトを再開します
- `閉じる`
  - 現在のプロジェクトを閉じます

保存対象には少なくとも以下が含まれます。

- 元にした PDF
- 作業リスト
- ラベル
- 印刷キュー
- 印刷順
- 印刷枚数

### 8. 未保存変更の扱い

- 画面上に `保存済み` / `未保存の変更あり` が表示されます
- 未保存の変更がある状態で別プロジェクトを開こうとすると警告します
- ブラウザを閉じようとしたときも、未保存なら警告が出ます

## フォルダ構成

このツール本体は以下のフォルダにあります。

`cardlist_referenced/pdf_card_editor/`

カード一覧 PDF / CSV はリポジトリ直下の `data/` を参照します。既定では `data/Card_ID List_JP.pdf` を自動で開きます。

主なファイル:

- `app.py`
  - Streamlit UI 本体
- `pdf_card_tool.py`
  - PDF 読み込み、リンク再生成、カード画像抽出、印刷用 PDF 生成
- `projects\`
  - 保存済みプロジェクト
- `.cache\`
  - プレビュー画像やカード抽出結果などのキャッシュ
- `launch_pdf_card_editor.cmd`
- `launch_pdf_card_editor.ps1`
- `launch_pdf_card_editor.vbs`
  - 起動補助ファイル

## 起動方法

### 方法1: Streamlit で起動

```powershell
python -m pip install -r pdf_tool_requirements.txt
streamlit run app.py
```

### 方法2: 起動ファイルを使う

以下のいずれかを実行します。

- `launch_pdf_card_editor.cmd`
- `launch_pdf_card_editor.ps1`
- `launch_pdf_card_editor.vbs`

必要に応じて、この起動ファイルへのショートカットをデスクトップに置くと、クリックだけで起動できます。

## 事前に必要なデータ

GitHub 上のこのツールを使うときは、`cardlist_referenced/` 直下に PDF を置く必要はありません。  
Kaggle から取得した以下を `data/` に置けば動作します。

- `Card_ID List_JP.pdf`
- `Card_ID List_EN.pdf`
- `JP_Card_Data.csv`
- `EN_Card_Data.csv`

## 基本的な使い方

### 1. PDF を選ぶ

上部の PDF 選択エリアから次を使えます。

- `元PDF`
- `最新出力PDF`
- `候補から選ぶ`
- `手入力で指定`

### 2. カードを探して選ぶ

- 左のカード一覧で検索や絞り込みを行います
- 必要なカードにチェックを入れます
- `選択を反映` を押します

### 3. 右側で目的別に操作する

- `印刷`
  - 印刷キューへ追加、枚数調整、並べ替え、印刷用 PDF 出力
- `作業リスト`
  - 作業リスト追加、作業リストから外す、作業リスト PDF 出力
- `ラベル`
  - ラベル適用、ラベル解除、整理

### 4. 続きから使いたいときは保存する

- 初回は `新規作成`
- 2回目以降は `上書き保存`

## このツールでできること / できないこと

### できること

- カード一覧から必要カードを選んで作業リスト化
- ラベル管理
- 作業状態の保存と再開
- 作業リストだけの PDF 生成
- 印刷用面付け PDF 生成
- ホバー / クリックによるカード画像プレビュー

### 初版ではやっていないこと

- PDF 内のカード画像位置を手動で調整する UI
- OS への直接印刷の強制実行
- インストーラ化
- ドラッグアンドドロップ専用 UI

## 補足

- 元 PDF は直接編集しません
- 出力 PDF は別ファイルとして作られます
- プロジェクト保存を使うと、作業用状態を持ったまま別日に続きから再開できます
- 作業リストベースで管理しているため、以前外したカードをあとから戻すこともできます
