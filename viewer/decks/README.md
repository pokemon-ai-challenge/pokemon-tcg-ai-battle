# デッキの追加方法

このフォルダに `*.csv` ファイルを置くと、ビジュアライザのデッキ選択に自動で追加されます。

## フォーマット

- 1 行 1 枚のカード ID（カンマ区切りも可）。合計 **60 枚**。
- 空行と `#` で始まる行は無視されます。
- 先頭の `# ...` 行は**日本語の表示名**として使われます（省略時はファイル名）。

カード ID は `data/EN_Card_Data.csv` / `data/JP_Card_Data.csv` を参照してください。
デッキ構築ルール（同名最大4枚・ACE SPEC は1枚・基本エネは無制限・Basic 1枚以上）は
ルートの `CLAUDE.md` を参照。

## 例

```
# 私のドラパルトデッキ
119
119
119
119
120
...（合計60行）
```

既定デッキ（`sample_submission/deck.csv`）は常に「Dragapult ex（既定）」として
選択肢に表示されます。
