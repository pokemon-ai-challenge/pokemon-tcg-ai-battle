# viewer/ai — AIを「置くだけ」で追加するフォルダ

このフォルダに AI を置くと、**サーバ再起動だけ**でビューアのAI選択肢に自動で出てきます
（`agents.py` を編集する必要はありません）。各AIは**別プロセスで実行**されるため、
別々のAIが `main.py` / `cg` / `tcg_rl` などの同名モジュールで衝突することはありません
（Kaggle本番と同じ隔離）。

## 置き方（2通り）

### ① フォルダごと（提出物と同じ形・おすすめ）
```
viewer/ai/<好きな名前>/
    main.py            # 必須。agent(obs_dict) -> list[int] を定義
    policy.npz         # 任意（そのAIが使うなら）
    tcg_rl/ , cg/ ...  # 任意（自前で同梱するなら。無ければリポジトリのものを使う）
```
→ **提出用の submission を解凍して置くだけ**でそのAIとして対戦できます。
AI名 = フォルダ名。

### ② 単体ファイル
```
viewer/ai/<好きな名前>.py    # agent(obs_dict) -> list[int] を定義
```
→ AI名 = ファイル名（拡張子なし）。リポジトリの `cg` / `tcg_rl` を使う軽い自作AI向き。

## お約束（インターフェース）
提出物とまったく同じです。

```python
def agent(obs_dict: dict) -> list[int]:
    ...  # obs_dict["select"]["option"] のインデックスのリストを返す
```

- `cg` や `tcg_rl` は import できます（無ければリポジトリの `sample_submission/` のものが使われます）。
- デッキ選択（`obs.select is None`）は**ビューア側で行う**ため、対戦中は呼ばれません（`[]` を返せばOK）。
- AIが `print` してもプロトコルは壊れません（標準出力ではなく標準エラーに退避されます）。
- 反則手・例外・プロセス落ちは、ビューア側が**自動で合法手にフォールバック**するので試合は止まりません。

## 反映
ファイルを置いたら**サーバを再起動**（`Ctrl+C` → `python viewer/server.py`）。
外部AIは一覧で「遅い(slow)」印が付きます（別プロセス往復のため）。

## 例
`random_ext/main.py` … 合法手からランダムに選ぶ最小サンプル（このフォルダ内に同梱）。
