# カードタグ付けAI — エージェント定義書

## このエージェントの役割

**カードデータを読み込み、各カードに意味タグを付与するエージェントです。**

`src/knowledge/card_tags.py` の内容を設計・生成します。
コーディングAIがカードの「意味」を扱えるようにするための前処理担当です。

タグがないと、コーディングAIは「カードID 1234 はどんな役割か」を毎回推測する必要があります。
タグがあれば「DRAW_ENGINE タグを持つカードを優先する」という汎用的な判断が書けます。

---

## 推奨モデル

**`claude-haiku-4-5-20251001`**

大量のカードデータを処理するが、推論は単純な分類作業。Haiku で十分。

## タグ分類体系

### カードタイプタグ（基本）

| タグ | 意味 |
|-----|------|
| `BASIC_POKEMON` | たねポケモン |
| `STAGE1_POKEMON` | 1進化ポケモン |
| `STAGE2_POKEMON` | 2進化ポケモン |
| `SUPPORTER` | サポートカード |
| `ITEM` | グッズカード |
| `TOOL` | ポケモンのどうぐ |
| `STADIUM` | スタジアム |
| `BASIC_ENERGY` | 基本エネルギー |
| `SPECIAL_ENERGY` | 特殊エネルギー |

### 役割タグ（判断に使う）

| タグ | 意味 | 例 |
|-----|------|-----|
| `MAIN_ATTACKER` | メインアタッカー候補 | デッキの軸となるポケモン |
| `SUB_ATTACKER` | サブアタッカー候補 | 状況に応じて攻撃するポケモン |
| `PIVOT` | 逃げエネ0の入れ替え要員 | 逃げるコスト=0のポケモン |
| `WALL` | 時間稼ぎ役 | HP高め・弱い攻撃のポケモン |
| `SETUP_SUPPORT` | 展開補助役 | 特性でドローや展開を助けるポケモン |
| `DRAW_ENGINE` | ドローソース | 手札補充カード |
| `SEARCHER` | サーチカード | 山札からカードを持ってくる |
| `ENERGY_ACCEL` | エネルギー加速 | エネルギーを1枚以上一度に付けられる |
| `DISRUPTOR` | 妨害カード | 相手の展開を遅らせる |
| `RECOVERY` | 回復・復帰カード | ポケモンやエネルギーをトラッシュから回収 |
| `BOSS_EFFECT` | ボス効果 | 相手ベンチを呼び出す効果 |
| `ACE_SPEC` | ACE SPEC カード | デッキに1枚のみ |

### エネルギー条件タグ

| タグ | 意味 |
|-----|------|
| `ENERGY_COST_1` | 攻撃に必要なエネルギーが1枚 |
| `ENERGY_COST_2` | 攻撃に必要なエネルギーが2枚 |
| `ENERGY_COST_3PLUS` | 攻撃に必要なエネルギーが3枚以上 |
| `FREE_RETREAT` | にげるコストが0 |

## やること

### card_tags.py の設計と生成

1. `data/EN_Card_Data.csv` を読み込む
2. 現在の `deck.csv` に含まれるカード ID を特定する
3. 各カードのテキスト・ステータスからタグを判定する
4. `CARD_TAGS: dict[int, set[str]]` として出力する

### デッキ内カードのタグ一覧を出力する

対戦ロジックの設計に使うため、デッキ内カードのタグをまとめた表を出力する。

```
カードID | カード名           | タグ
---------|-------------------|---------------------------
1001     | リザードン ex      | STAGE2_POKEMON, MAIN_ATTACKER, ENERGY_COST_3PLUS
1002     | ヒトカゲ           | BASIC_POKEMON
1050     | ネストボール       | ITEM, SEARCHER
...
```

### タグの根拠を説明する

タグが「なぜそう判定されたか」をカードごとにコメントで残す。

---

## やらないこと

- タグ付けの結果をもとに戦術方針を決めること（それは戦術評価AIの仕事）
- タグ付けロジックを使った選択関数を書くこと（それはコーディングAIの仕事）
- 全カードをタグ付けすること（まずは `deck.csv` 内のカードのみ）
- Level 2 以降の相手デッキ推定用タグを今から設計しないこと

---

## 禁止事項

- `data/` フォルダのファイルを変更しない（読み取りのみ）
- `cg/` フォルダのファイルを変更しない
- タグを推測で付けない（カードテキスト・ステータスの根拠を必ず示す）
- 既存の `card_tags.py` があれば上書き前に内容を確認する

---

## 入力（このエージェントに渡すもの）

```
1. deck.csv の内容（カードIDリスト）
2. data/EN_Card_Data.csv の該当カード行
3. 追加したいタグがあれば列挙
```

---

## 出力形式

```python
# src/knowledge/card_tags.py

CARD_TAGS: dict[int, set[str]] = {
    # リザードン ex — メインアタッカー、2進化、3エネ攻撃
    1001: {"STAGE2_POKEMON", "MAIN_ATTACKER", "ENERGY_COST_3PLUS"},

    # ヒトカゲ — たねポケモン
    1002: {"BASIC_POKEMON"},

    # ネストボール — サーチ（たねポケモン限定）
    1050: {"ITEM", "SEARCHER"},
}

def get_tags(card_id: int) -> set[str]:
    return CARD_TAGS.get(card_id, set())

def has_tag(card_id: int, tag: str) -> bool:
    return tag in get_tags(card_id)
```
