# RL 設計思想と前提条件

## 概要

本実装は **Flat Monte Carlo Search（平坦モンテカルロ探索）** をベースにしたエージェントです。
強化学習の観点から以下のように定式化しています。

---

## 強化学習としての定式化

| 要素 | 内容 |
|------|------|
| **状態 S** | `Observation`（盤面・手札・サイドカード・ログ） |
| **行動 A** | `list[int]`（選択肢インデックスのリスト） |
| **報酬 R** | 勝利=+1, 敗北=-1, 途中=評価関数値 |
| **方策 π** | `agent(obs_dict)` 関数 |
| **価値 V(s)** | `evaluate(obs, my_index)` ヒューリスティック関数 |
| **行動価値 Q(s,a)** | モンテカルロロールアウトの平均報酬 |

---

## アルゴリズム: Flat Monte Carlo Search

### 基本方針

ゲームエンジンの `search_begin` / `search_step` API を用いて、
現在の手番で取れる各行動 `a` について複数回のランダムロールアウトを行い、
期待価値 `Q(s, a)` が最大の行動を返す。

```
for each candidate action a:
    Q(s, a) = mean over K rollouts of R(a)

return argmax_a Q(s, a)
```

### ロールアウト戦略

- 最大ステップ数: `ROLLOUT_DEPTH = 25`
- 各ステップでランダムな合法手を選択
- 終端状態（勝敗確定）に達したら実際の結果 ±1 を返す
- 時間切れや途中終了時はヒューリスティック評価関数を使用

---

## 評価関数 `evaluate(obs, my_index)`

盤面価値を[-1, 1]で近似する。

```
価値 = 0.70 × サイド差分
     + 0.15 × HP比率差分
     + 0.04 × ベンチ枚数差分
     + 0.02 × エネルギー枚数（最大3）
```

### サイド差分

`(相手残サイド - 自分残サイド) / 6`

- 6枚取り切ったら勝利 → 最重要指標

### HP比率差分

`(自分のHP/最大HP) - (相手のHP/最大HP)`

- バトルポケモンの生存状況

---

## アーキテクチャ

```
agent(obs_dict)
    ├─ デッキ選択: read_deck_csv()
    ├─ MC探索: search_begin() → _flat_mc_search()
    │              └─ search_step() × N (各候補行動)
    │                   └─ _rollout() (ランダムシミュレーション)
    └─ フォールバック: _heuristic()
```

---

## 前提条件

### ゲームエンジン

- `cg/cg.dll`（Windows）または `cg/libcg.so`（Linux）が存在する
- `search_begin` に渡す相手の非公開情報（手札・デッキ）は推測値で可
- `search_step` で無効な行動を渡すと例外が発生する

### デッキ

- 60枚のカードIDが `deck.csv` に記載されている
- 少なくとも1枚の基本ポケモンを含む

### Python バージョン

- Python 3.12+ 必須（`list[X]`, `X | Y` 型ヒント構文を使用）

---

## 相手デッキ予測の戦略

`search_begin()` は相手の非公開情報を要求する。
以下の優先順位で予測する:

1. ゲーム中に公開された相手カード（ログから収集）
2. 自分のデッキカードで補完
3. 裏向きバトルポケモン → デッキ中の基本ポケモン

この推測は不正確だが、シミュレーション精度よりも「多様なシナリオを素早く評価する」ことを優先している。

---

## ヒューリスティック（フォールバック）

MC探索が失敗した場合、コンテキスト別のルールベースを使用:

| SelectContext | 戦略 |
|---------------|------|
| MAIN | 進化 > エネ付け > 特性 > 攻撃 > カード > END |
| SETUP_ACTIVE | HP が最も高いポケモンをバトル場へ |
| SETUP_BENCH | できるだけ多くベンチへ展開 |
| その他 | 最低限必要な数だけ先頭から選択 |

| Level | 手法 |
