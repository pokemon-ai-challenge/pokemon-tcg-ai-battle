## 敗因の徹底分析(要点)

1. **負けの76%が「サイドレース大差(blowout)」**。平均ターン 12.1 と**短く**、平均残サイド 5.1
   =**サイドをほぼ取れないまま(6→5.1)一方的に走られて負けている**。序盤展開停滞(Alakazamを
   早期に出せない)は16件中2件だけなので、原因は「展開が止まる」ではなく **攻撃の立ち上がりが
   相手のアグロに間に合っていない**(mega_lucario/mega_starmie/dragapult 等の速い攻めに轢かれる)。
   → **速度/受けの弱さ**が最大の構造的課題。手札干渉(クセロシキ)はミラーには効くが、速いアグロ
   相手には遅効なため blowout を止めきれない。

2. **crustle が明確な苦手(2-4)、しかも負けの3/4が deck_out(山札切れ)**。crustle は妨害/長期戦型で
   **こちらを山札切れに追い込む**。avg_turn 33.7 の長期戦。ドローエンジンを回すほど自分の山札を
   削る側面があり、対 crustle では**引きすぎ=自滅**の構図。→ 対 crustle は「引く量を抑える/
   山札を守る」プレイor構築が要る。

3. **mega_starmie_ex に 0-3(全 blowout)**。サンプルは少ない(3件)が全敗・全て大差。速い水/超系の
   アグロに轢かれている可能性。**明確な穴として要監視・対策候補**。

4. deck_out は全体では 14%(全て crustle)。旧提出時に懸念された「構造的山札切れ」は、対 crustle
   以外ではほぼ解消している。
