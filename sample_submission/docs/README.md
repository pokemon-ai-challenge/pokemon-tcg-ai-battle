# docs

`sample_submission/docs/` は、実装コードそのものではなく、設計・評価・計画に関する文書を置く場所です。

```text
docs/
├── architecture/             # アーキテクチャ設計、責務分割、構造メモ
├── evaluation/               # 実験結果、比較メモ、評価手順
├── plans/                    # 実装計画、タスク分解、進行メモ

```

## ディレクトリの役割

- `architecture/`
  AI の構成、責務分割、モジュール境界、設計判断のメモを置きます。
- `evaluation/`
  対戦結果、ベースライン比較、検証観点、評価の振り返りを置きます。
- `plans/`
  今後の実装計画、タスク整理、段階的な進め方のメモを置きます。
