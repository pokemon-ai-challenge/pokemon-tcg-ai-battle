# rough_predictor score tuning

`sample_submission/ptcg_ai/opponent_modeling/rough_predictor.json` の
`confident_score` とスコア調整の意図を、デッキ別に追えるようにしたメモ。
作成時点の working tree の config を正としている。

## 共通方針

- `normalized_score = score / confident_score` を候補比較と `unknown` 判定に使う。
- 確定条件は `prediction_decision` 側で見る。現在は `min_evidence_count: 2`、
  `min_top_normalized_score: 1.0`、`min_normalized_margin: 0.2`。
- `min_score` は各 archetype に残っているが、現行の確定判定では直接使っていない。
- `confidence` は後方互換フィールドで、実質的な表示・判定値は `match_rate` / `normalized_score`。
- 汎用カードは原則 0 点。`generic_cards` には、除外理由を追跡したいものだけ明示する。
  現在は `アンフェアスタンプ` と `スボミー`。
- `ace_spec_bonus` は `1.0` なので、ACE SPEC であること自体は追加倍率にしない。
- `ふしぎなアメ` と進化ラインが同時に見えた 2 進化系には、共通の
  `evolution_candy_combo` で `+7.1` を足す。
- 到達率は `score / confident_score * 100`。100%以上がスコア上の確定ラインで、
  実際の確定には根拠数 2 個以上と 2 位候補との差 `0.2` 以上も必要。
- 同じ `line_key` を持つカードは同時に見えても二重加点しない。
  例: `ヤドキング` と `ヤドン` が同時に見えても、先に評価された主軸側だけを加点する。

## role weight

| role | weight | 使い方 |
|---|---:|---|
| `anchor` | 10 | デッキの主軸。単体で最も強い根拠。 |
| `exclusive_core` | 9.5 | そのデッキ以外ではほぼ採用されない専用カード。単体は強く、確定は根拠数で抑える。 |
| `signature` | 8 | 専用寄りカード。anchor ほどではないが候補を大きく絞る。 |
| `strong_evolution_line` | 8 | 主軸に直結する進化元。単体でも高めに扱う。 |
| `shared_anchor` | 7 | 複数デッキで共有される主軸級カード。 |
| `shared_line` | 5 | 複数デッキで共有される進化ライン。 |
| `evolution_line` | 4 | 通常の進化元・中間進化。 |
| `core` | 3 | 採用率が高い固定ギミック・専用サポート。 |
| `energy` | 2 | 色や専用エネルギーの補助根拠。 |
| `flex` | 1 | 構築により採用される弱い根拠。 |
| `generic` | 0 | 汎用カード。判定根拠にしない。 |

## 今回の主な差分

- `exclusive_core: 9.5` と `strong_evolution_line: 8` を追加。
- `Nのゾロアークex` は、N 専用カードを `exclusive_core` に上げ、`モモワロウex` / `シアノ` は
  単体では弱い `flex` に下げた。その代わり、N 系カードと同時に見えた場合だけ `+3` combo にする。
- `おまつりおんど` は `シェイミ` を `core` から `flex` に下げた。
- `ゲッコウガex` は `偉大な大樹 + ゲッコウガ進化ライン` に `+4.6` combo を追加。
- `シロナのガブリアスex` は `シロナのパワーウエイト` を anchor 級に上げ、
  `シロナのロズレイド/ロゼリア` と `シロナのミカルゲ` を `signature` に整理。
- `ストリンダー` は `エレズン` を `signature` 相当の進化ライン根拠にしつつ、
  `line_key` で本体との二重加点を防ぐ。毒系の周辺カードは `flex` に寄せた。
- `ヤドキング` は `ヤドン` を `strong_evolution_line` にし、ワザ先の `ムチュール` / `コノヨザル`
  を `core` に上げた。根拠が増えやすくなったため `confident_score` を `12 -> 13` に上げた。
- `ロケット団のドンカラス` は `ロケット団のヤミカラス` を `strong_evolution_line` にし、
  ロケット団系トレーナーズを `core` に追加。`ロケット団のフリーザー` は共有寄りなので `flex` に下げた。
- `マリィのオーロンゲex`、`イワパレス`、`メガユキメノコex`、`メガユキノオーex`、
  `メガスターミーex`、`ブリジュラスex` を追加。主軸本体とその進化元は同じ `line_key` にし、
  同時に見えても二重加点しない。`ユキワラシ/ユキメノコ` のような氷系共有ラインは
  `flex` や弱い進化ラインに寄せ、core 加点で過確定しないようにした。
