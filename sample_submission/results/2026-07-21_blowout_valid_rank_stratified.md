# 検証(blowout piloting) 追補: リーダーボード順位別のAlakazam勝率(天井の清潔な推定)

- 日付: 2026-07-21
- ブランチ: `experiment/pimc-hidden-info-integration`
- 対象: [blowout-piloting-validation-implementation-plan.md](../plans/individual/shogo/blowout-piloting-validation-implementation-plan.md) Step1 の追補
- コード変更: なし。分析専用スクリプト(スクラッチパッド、`_diag_blowout_valid.analyze_replay` を再利用し `episodes_master.jsonl` の `rank_at_fetch` を join)。

## 動機

Step1/Step3 の「第三者Alakazam勝率54.0%」はプール全体の平均で、様々な順位帯を含む。
また Step3 の「勝率上位チーム63.8%」は**勝率で選別しているため循環(選択バイアス)**があり
「到達可能な天井」と読むのは行き過ぎ、と本文でも注記していた。そこで**勝率で選別しない
リーダーボード順位(`rank_at_fetch`)で層別**し、真の上位帯の勝率を清潔に推定した。

## 方法

自チーム以外のAlakazamパイロットの決着試合2515件(既存検出を再利用)を、`episodes_master.jsonl`
の (episode_id, team_name) → `rank_at_fetch` で join(2515件全てjoin成功)。順位帯ごとに勝率を集計。
join key は**ファイル名由来のepisode_id**(replay JSON の `id` フィールドはUUIDで master と不一致)。

## 結果

| リーダーボード順位帯 | 試合数 | 勝ち | 勝率 |
|---|---|---|---|
| 1〜20位 | 359 | 219 | **61.0%** |
| 201〜1000位 | 931 | 515 | 55.3% |
| 1001位以下 | 682 | 355 | 52.1% |
| 順位不明 | 539 | 265 | 49.2% |
| (参考)自チーム | 363 | 162 | **44.6%** |

累積: rank≤20 = **61.0%**(359試合) / rank≤200 = 61.4%(363試合) / rank≤1000 = 57.0%(1294試合)。
(rank 21-50 は該当0件、51-200 は4件のみのため、上位帯は実質「≤20位」で代表される。)

## わかったこと

1. **単調な技量勾配**: 順位不明49.2% → 1001位以下52.1% → 201-1000位55.3% → 上位≤200位61.4%。
   順位が上がるほど勝率が上がる。**回し方(技量)が勝率を押し上げる＝デッキが天井ではない**ことの、
   マッチメイク交絡に比較的強い直接証拠。
2. **上位帯の清潔な天井は約61%**(リーダーボード≤20位、359試合の堅い標本)。**Step1で報告した
   プール平均54%は、下位・不明ランクに引きずり下げられた値であり、上位の天井ではなかった。**
3. **自チームの伸びしろは約+16pt**(44.6% → 61%)。[[project_loss_taxonomy]]/検証本文で
   「+9pt/天井54%」としていた見積もりは過小評価であり、本追補で**天井≈61%・伸びしろ≈+16pt**に訂正する。

## 含意(方針)

- **PolicyModel改善の投資価値は前回想定より大きい**(現実的目標61%)。
- **学習データの技量集中レバーが具体化**: 現状 `policy_net/build_features.py` は緩い順位重み
  (1-50位1.5倍〜1001位以下1.0倍)で全プール(平均54%層)を模倣している。**リーダーボード上位
  (≤20〜≤200位、61%層)に集中**して再学習すれば天井を61%側へ引き上げられる。本追補の順位データが
  その選別基準に使える。
- 留保: 61%が上位帯の天井なので、それ以上(70%+)はデッキ変更か模倣超え(self-play RL)が要る。
  ただし44.6%→61%だけでも実Kaggleでは大きな改善。

## 限界

- `rank_at_fetch` はプレイヤーの**総合**リーダーボード順位で、Alakazam固有の技量とは限らない(技量の代理)。
- 上位帯は対戦相手分布が異なりうる(マッチメイク交絡)が、順位に対して単調に勝率が上がることが
  その交絡だけでは説明しにくい強いシグナルになっている。
- 61%(≤20位)は堅い集計値。個別の少数標本チームは72〜81%に達するが標本が小さくノイジー。
